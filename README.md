# CD AI for iPhone

Open **https://hashalit2811.github.io/Iphone-CD-AI/** in Safari on your iPhone, tap **Share**,
then **Add to Home Screen**. CD AI gets its own icon, opens full screen, and works offline.

This repository only holds the built web app, served by GitHub Pages. The source code is in the
private CD-AI repository (`mobile/`, built with `WEB_BASE=/Iphone-CD-AI/ npm run build:web`).
